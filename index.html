How to use SQLDEX

Switch direction

Top-right toggle: SQL → JSON or JSON → SQL. Each side remembers its own pasted text and its own options.

SQL → JSON

  • Paste from SSMS (Copy with Headers), Excel, or a CSV/TSV/pipe file into the input screen, or drag a file onto it.
  • Input format auto-detects tabs/commas/semicolons/pipes/"Results to Text".
  • Output shape: array of objects, one object keyed by the 1st column, columns+rows, or JSON Lines.
  • Property names / Indent control the JSON keys' casing and spacing.
  • Checkboxes: treat 1st row as headers, drop blank-header columns, convert NULL/empty cells, detect numbers & booleans, convert dates to ISO 8601, trim spaces.

JSON → SQL

  • Paste a JSON array of objects or JSON Lines. Each key becomes a column.
  • Set the table name, statement type (batched INSERT, one-row-per-statement INSERT, or UPDATE by the 1st column), and column name casing. Table names you've used before show up as suggestions (grouped by schema) as you type.
  • Checkboxes: emit a CREATE TABLE, use N'…'/NVARCHAR for Unicode text, wrap with IDENTITY_INSERT ON.
  • Transaction wrapping: none, a plain transaction, TRY/CATCH with rollback on error, or a test run (BEGIN TRAN…ROLLBACK TRAN, nothing is committed).

Columns… button

Opens a checklist of every detected column so you can include/exclude columns without editing the source data — works in both directions, with Select all / Select none.

Output panel

Copy or Download the converted result. Sample fills the input with example data; Clear empties it.

Good to know

Your option choices are saved in this browser (localStorage) and restored next time. Nothing you paste is ever uploaded — everything runs locally.
