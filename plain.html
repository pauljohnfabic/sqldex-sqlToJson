sqlToJson

Paste a table from Excel, Google Sheets or SQL Server results, headers included, and get JSON back with one property per column.

Excel / Google Sheets: select the cells including the header row, then Ctrl+C.
SQL Server (SSMS): select your results → right-click → Copy with Headers (Ctrl+Shift+C).
Then paste into panel 1. CSV and “Results to Text” output work too.
